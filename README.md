# AI Content Creation Agent

An AI agent built with Anvia and TypeScript for generating a video content package through three related tools:

1. **Content Idea** — generates a video title and narrative idea.
2. **Script Maker** — transforms the content idea into a scene-by-scene script.
3. **Technical Shoot** — transforms the script into a scene-by-scene technical shooting plan.

The agent also uses **Prisma-based conversation memory with compaction** so conversation history can persist across sessions while older history can be summarized when the configured token threshold is reached.

## Features

* Anvia Agent
* Three related tools:

  * `contentIdea`
  * `scriptMaker`
  * `technicalShoot`
* Scene-by-scene script generation
* Scene-by-scene technical shooting plan
* Prisma memory store
* Automatic conversation compaction
* Persistent conversation history using a session
* TypeScript
* Environment-based API configuration

## Agent Workflow

The agent coordinates the tools based on the user's request.

```text
User
 │
 ▼
Anvia Agent
 │
 ├── contentIdea
 │       │
 │       ▼
 │   Title + Idea
 │
 ├── scriptMaker
 │       │
 │       ▼
 │   Scene-by-scene Script
 │
 └── technicalShoot
         │
         ▼
     Shooting Plan
```

The three tools are related and have separate responsibilities:

### 1. Content Idea

Produces:

```text
Title
Idea
```

### 2. Script Maker

Produces a scene-by-scene script containing:

```text
Scene
Characters
Dialogue
Atmosphere
```

### 3. Technical Shoot

Produces a scene-by-scene shooting plan containing:

```text
Scene
Shot Type
Camera Movement
Character Position
Object Position
```

## Memory and Compaction

The agent uses Prisma as its persistent memory store.

A conversation is associated with a session. Reusing the same session allows the agent to load previous conversation history on subsequent runs.

```text
Agent
 │
 ▼
Prisma Memory Store
 │
 ├── Conversation History
 │
 └── Compaction Checkpoint
```

Compaction is enabled so that when the model-facing memory projection reaches the configured token threshold, older conversation history can be summarized while recent turns are retained.

The canonical conversation history remains stored in Prisma. Compaction creates a summary checkpoint for the model-facing context rather than deleting the original conversation history.

## Testing Compaction

Compaction is configured on the Agent's memory configuration.

When the model-facing conversation projection exceeds the configured threshold and an older prefix can be compacted, Anvia creates a summary checkpoint while retaining the configured recent turns.

For testing purposes, the compaction threshold can be configured lower than a production value so that the behavior can be demonstrated with a shorter conversation.

The Anvia runtime emits a `memory_compaction` event when automatic compaction occurs.
